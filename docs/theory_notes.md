# MIMO-OFDM物理层算法理论笔记

## 1. OFDM基本原理

OFDM通过多个相互正交的子载波并行传输数据，
利用IFFT实现频域到时域的转换，接收端通过FFT恢复频域符号。

循环前缀（CP）通过复制OFDM符号末尾的部分采样，
在CP长度足够且同步正确时，可减轻多径引起的符号间干扰，
并使信道卷积近似转化为频域逐子载波乘法。

## 2. MIMO系统模型

MIMO系统利用多个发送和接收天线传输信号。

基本模型：

y = Hx + n

其中：
- x：发送信号向量
- y：接收信号向量
- H：MIMO信道矩阵
- n：加性噪声

对于2×2 MIMO，H为2×2复数矩阵。

## 3. DMRS信道估计

DMRS是接收端已知的解调参考信号，
用于估计无线信道响应。

单天线情况下，LS估计为：

H_hat = Y_DMRS / X_DMRS

通过导频位置的估计结果进行插值，
可以获得其他数据子载波位置的信道响应。

多天线情况下，还需考虑不同天线端口的导频分离。

## 4. ZF均衡算法

ZF（Zero Forcing）通过求解信道矩阵的逆问题，
尽可能消除不同数据流之间的干扰。

对于满列秩信道：

W_ZF = (H^H H)^(-1) H^H

x_hat = W_ZF y

其中H^H表示共轭转置。

优点：
- 原理简单
- 不需要噪声功率估计

缺点：
- 信道矩阵病态时可能明显放大噪声
- 低SNR情况下性能可能较差

## 5. MMSE均衡算法

MMSE（Minimum Mean Square Error）通过最小化
发送信号与估计信号之间的均方误差实现均衡。

在单位发送信号协方差和白噪声假设下：

W_MMSE = (H^H H + sigma_n² I)^(-1) H^H

x_hat = W_MMSE y

其中：
- sigma_n²：噪声方差
- I：单位矩阵

MMSE综合考虑干扰抑制与噪声放大问题，
在低SNR及病态信道情况下通常比ZF更稳定。

## 6. ZF与MMSE对比

| 比较项目 | ZF | MMSE |
|---|---|---|
| 核心目标 | 消除空间流间干扰 | 最小化均方误差 |
| 噪声方差 | 不需要 | 需要 |
| 噪声放大 | 可能较明显 | 通常得到改善 |
| 低SNR性能 | 可能较差 | 通常较好 |
| 高SNR表现 | 在适当条件下趋近MMSE | 趋近ZF |
