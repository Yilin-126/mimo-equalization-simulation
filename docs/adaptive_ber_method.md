# BER自适应统计方法与实验变量控制说明

## 1. 目的

本模块用于改进MIMO-OFDM链路的BER-SNR性能评估方法。

原先采用固定仿真帧数，在高SNR条件下可能无法获得足够的误码样本，导致BER估计缺乏统计支撑。

本次改进引入目标误码数与最大测试比特数双重停止条件，并将发送比特、噪声和信道的随机数生成器分开管理，提高实验的可复现性。

## 2. 自适应BER统计原理

BER定义为：

`BER = N_errors / N_bits`

其中：

- `N_errors`：累计错误比特数
- `N_bits`：累计测试比特数

对于每个SNR点，分别统计ZF和MMSE的误码数量。

当满足以下任一条件时，停止当前SNR的仿真：

**条件一：达到目标误码数**

ZF与MMSE累计误码均达到200个。

**条件二：达到最大测试预算**

累计测试比特数达到最大预算，或剩余预算不足以再运行一个完整OFDM帧。

当前配置：

- 目标误码数：200
- 最大测试比特数：2,016,000
- OFDM符号数：14
- 有效子载波数：1200
- 发送天线数：2
- 调制方式：QPSK

每帧对应：

`14 × 1200 × 2 × 2 = 67,200 bits`

因此每个SNR最多测试30帧。

## 3. 停止条件实现

停止逻辑位于：

`src/mimo_sim/ber_stopping.py`

主要函数：

`get_stop_reason()`

输入：

- ZF累计误码数
- MMSE累计误码数
- 已测试比特数
- 目标误码数
- 最大比特数

输出：

- `target_reached`
- `max_bits_reached`
- `None`，表示继续仿真

相关测试文件：

`tests/test_ber_stopping.py`

测试覆盖目标误码达成、单算法未达标、最大比特数限制以及非法参数。

## 5. 随机种子独立管理

随机数控制模块：

`src/mimo_sim/random_control.py`

使用NumPy的独立随机数生成器：

- `bits`：发送比特随机流
- `noise`：噪声随机流
- `channel`：随机信道生成流

当前配置为：

```json
{
  "random_control": {
    "enabled": true,
    "bit_seed": 20261106,
    "noise_seed": 20261107,
    "channel_seed": 20261108,
    "reuse_realizations": true
  }
}
```

三个随机数流由不同种子初始化，避免生成发送比特时消耗噪声或信道所需的随机数。

目前 `run_ber_scan.py` 已接入独立的比特和噪声随机数流。

由于当前BER测试使用固定2×2信道矩阵，尚未使用信道随机流生成随机信道。

配置中的 `enabled` 和 `reuse_realizations` 目前尚未实现对应的开关控制行为，后续实验扩展前需要完善，不能将其视为已生效功能。

## 6. 同组对比实验的变量控制

### 6.1 ZF与MMSE对比

在同一SNR点：

1. 生成一批发送比特。
2. 使用同一信道矩阵。
3. 生成一次接收噪声。
4. 对同一接收信号分别执行ZF与MMSE均衡。
5. 统计两种算法的误码数量。

因此，同组ZF/MMSE比较使用完全相同的发送数据和接收信号。

### 6.2 不同信道对比

后续扩展多径信道、相关MIMO信道时，应做到：

- 使用相同的发送比特序列。
- 使用独立且可重复的噪声随机数流。
- 使用固定的信道随机种子。
- 明确每个场景允许改变的信道参数。
- 尽可能使用共同的基础随机样本生成不同信道。
- 固定SNR定义及噪声归一化规则。

需要注意，相同随机种子并不自动保证不同信道模型生成相同的随机信道样本。

如果不同模型消耗随机数的方式不同，还需要显式控制基础随机样本及其变换方式。

当前不同信道模型的统一变量控制尚未完成集成验证。

## 8. 高SNR统计限制

在高SNR条件下，误码概率较低。

即使达到最大测试比特数，也可能没有观察到任何误码。

因此：

`Measured BER = 0`

仅表示本次有限样本中未观察到错误，并不意味着真实BER严格等于零。

在独立比特错误的近似假设下，当N个测试比特中没有观察到错误时，单侧95%置信上界可近似写为：

`BER_upper ≈ 3 / N`

例如：

`N = 2,016,000`

得到：

`BER_upper ≈ 1.49e-6`

这一近似依赖误码事件的统计假设。对于存在相关性的链路误码，不能直接保证相同覆盖概率。

## 13. 按SNR与帧编号固定随机样本

为避免自适应BER仿真在不同SNR点提前停止时影响后续随机序列，新增按实验索引生成样本的机制。

主要接口：

`create_frame_samples(config, snr_index, frame_index, num_bits, noise_shape, channel_shape)`

该函数使用三个独立随机种子，结合SNR编号和帧编号，分别生成：

- 发送比特序列
- 单位方差复高斯噪声基础样本
- 单位方差复高斯信道基础样本

相同配置、SNR编号和帧编号下，生成结果完全一致，不受其他实验运行顺序及提前停止影响。

当前 `scripts/run_ber_scan.py` 已接入该接口。

### 13.2 变量控制边界

当前跨场景测试验证了基础随机样本的复用能力，但尚未实现完整的多信道BER对比流程。

在不同信道场景下，需要明确采用以下哪一种噪声控制策略：

- 固定绝对噪声方差：不同场景使用同一基础噪声样本及相同噪声功率，接收SNR可能随信道变化。
- 固定接收SNR：不同场景根据统一的信号功率定义调整噪声幅度，使用相同基础噪声样本，但实际噪声数值可能不同。

两种策略不可混用，实验报告必须说明采用哪种策略。

此外，配置项 `reuse_realizations` 尚未实现可切换行为，目前不能认为多信道场景控制已经全部完成。
